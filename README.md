# Quizz Scanner

AI-powered question scanner and answer system.

## Planned features

- Type a question
- Scan a question
- Upload PDF, Word and PowerPoint files
- Upload photos
- Upload full-length videos
- Answer from uploaded resources
- Internet fallback
- Continuous screen scanning
- Fast answer generation

## Security

The OpenAI API key must never be placed in frontend JavaScript.

It will be stored securely as a server-side environment variable.
